# 100 Days of DevOps

2+ years DevOps/Cloud experience. Documenting 100 days of daily 
hands-on practice — real commands, real problems solved, no basics.

## Phases
- Phase 1 (Day 1–30): Advanced Linux + Shell Scripting + Git
- Phase 2 (Day 31–60): Docker (networking, multi-stage builds, security)
- Phase 3 (Day 61–85): Terraform + AWS Infra as Code
- Phase 4 (Day 86–100): Monitoring (Prometheus + Grafana) + Capstone

## Capstone
App → Docker → Terraform → Monitoring, deployed on AWS (ECS + EC2)
